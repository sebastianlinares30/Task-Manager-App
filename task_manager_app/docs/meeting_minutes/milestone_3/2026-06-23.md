## Architecture Discussion

The team reviewed how the technologies would work together within the application.

The agreed architecture is:

- HTML
- CSS
- JavaScript
- Python Backend
- SQLite Database

The team discussed using JavaScript to communicate with the existing Python backend rather than replacing the current Python implementation. Python will continue handling the application's business logic while SQLite will provide persistent data storage.

The group also recognized that communication between JavaScript and Python would be one of the primary technical challenges during this milestone.
